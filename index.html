Users & Access

Anyone can create their own account (they start as Guest, view-only). An Administrator must promote a person to Administrator here before they can add, edit, or delete anything.

0 users
New accounts sign themselves up from the sign-in screen ("Create a new account") — there is no "Add a user" button here, since each person needs to set their own password. Once someone has signed up, their name appears below and an Administrator can change their role.
Tick a branch to let a Guest add, edit, or delete in that branch's sections (Admin Branch → Employees; Record Branch → Cases, Hearings, Results, Dispatch; Accounts Branch → Token Register). These checkboxes apply only to Guests — an Administrator already has full access everywhere. A section without permission stays visible for viewing and printing; its Add/Edit/Delete controls are shown but disabled.
